# Training Planner

Автор: [Ваше имя и фамилия]

Описание:
Это простое GUI-приложение для планирования тренировок. Позволяет добавлять записи, фильтровать по типу и дате, сохранять и загружать данные в JSON-файл.

Использование:
1. Введите дату в формате YYYY-MM-DD.
2. Введите тип тренировки.
3. Укажите длительность в минутах.
4. Нажмите «Добавить тренировку».
5. Для фильтрации используйте поля фильтров и кнопку «Применить фильтр».
6. Для сброса фильтров используйте кнопку «Сбросить фильтр».

Пример тестов:
- Добавьте тренировку с датой 2024-04-20, тип «Кардио», 30 минут.
- Отфильтруйте по типу «Кардио».
